# 👑 Princess Day Envelope Letter

A simple, cute envelope-letter page for Princess Day (18 Nov). Tap the envelope, confetti pops, and a letter opens. Share it with your bestie, girlfriend or love.

**Made by Storymint Studio** · [@storymint.studio](https://instagram.com/storymint.studio)

## What's inside

- `index.html`: the whole page (HTML + CSS + JS in one file, no install needed)

## How to use

1. Open `index.html` in any browser (phone or laptop).
2. Tap the envelope.

## Change the message

Open the file in any text editor, find this line in the script and edit the text:

```js
var MESSAGE="You’re the princess of my heart…\nThank you for …\nHappy Princess Day! 💗";
```

`\n` means a new line. Emojis work too.

## Share it online

A file on your phone can't be opened by others. To share it:

1. Rename the file to `index.html`.
2. Upload it to [Netlify Drop](https://app.netlify.com/drop) or GitHub Pages.
3. Send the link you get.

## Good to know

- Fonts (Fredoka, Caveat, Poppins) load from Google Fonts, so the page needs internet to look its best.
- Works on all phone sizes. Tested at 360, 375 and 390 px wide.
- The sticker images are embedded in the file as `<img class="stk" ...>` tags. If you plan to share or sell this publicly, replace them with images you have the rights to use.
